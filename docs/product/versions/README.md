# 产品文档版本

当前版本线：[1.5.0](1.5.0/README.md)。`1.5.0` 是首次整理的产品文档版本，不代表同名软件发布，也不改变已有代码 tag `v1.0.0`。

版本目录收纳业务、需求、功能和交付证据的当前正文。文档版本号采用 `主版本.次版本.修订号`；同一版本线内的修订（如 `1.5.1`）继续编辑 `1.5.0/` 中受影响的文件，并在该目录的 `CHANGELOG.md` 记录已确认的变更。形成新的业务范围并确认下一条版本线时，才新建版本目录，例如 `1.6.0/`。普通草稿和进度提交不自动升级文档版本。

每次正式确认文档基线时，先核对变更及链接，再为对应的 Git 提交创建带说明的 `docs-vX.Y.Z` 标签。已发布标签不改指向；旧版本内容通过标签查看。版本号与标签的对应关系记录在版本目录的 `README.md`。后续版本如需继承既有要求，应引用上一基线及变更项，避免复制整套正文。

重要需求变更至少记录需求编号、原因、影响范围、决定、验收条件变化和对应提交；实现状态仍以实际验证证据为准。文档版本与代码发布独立编号，交付说明中再关联代码提交或发布 tag。
