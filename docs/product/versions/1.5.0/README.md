# NoteAgent 产品文档 1.5.0

**状态：** 文档版本线 1.5，当前修订 1.5.1 已核对确认；已固定基线仍为 1.5.0。本文档描述现有产品方向和已记录的实现进度；规划中的能力不因纳入本目录而视为交付。

**版本身份：** 目录 `1.5.0/` 是产品文档版本线的起始目录，独立于旧路线图的 V1/V2/V3 能力阶段、应用包版本和代码 tag `v1.0.0`。同线修订 `1.5.1` 留在本目录，基线标签名为 `docs-v1.5.1`。首次整理基线由 `docs-v1.5.0` 保留。

| 阅读顺序 | 文件 | 回答的问题 |
|---|---|---|
| 1 | [业务架构](business-architecture.md) | 产品服务谁、解决什么问题、业务对象与边界是什么 |

原有 V1/V2/V3 条目保留其历史含义。它们是候选能力和旧里程碑的来源，不自动成为后续软件版本的交付承诺；选定下一次交付范围时再从中确定具体需求。

## 版本基线来源

本目录的四份原有正文从 `docs/product/` 原位迁入，仅为路径变化调整相对链接。1.5.1 修订移除了外层兼容入口，并把仓库内指向它们的链接改为版本目录路径。已有验收结论沿用原记录，没有重新运行测试或补造缺失的人工证据。V1 验收的历史代码身份为 `v1.0.0`；本次文档基线记录的是整理时的文档状态，不能倒填为当时的软件需求批准记录。

当前系统行为以 [现行架构](../../../architecture/architecture.md) 和代码为准；任务执行见 [计划目录](../../../plans/README.md)；评测与报告见 [evals](../../../../evals/README.md)。
