# 文档版本变更记录

## 1.5.1（2026-10-01）：收敛产品正文入口

- 删除 `docs/product/` 外层四份兼容入口，产品正文只在本版本目录维护。
- 将仓库内可编辑文档中指向旧入口的 Markdown 链接改为版本目录路径；历史计划中的文字性旧路径仍表示当时的文件位置。
- 在 `versions/README.md` 补全日常迭代流程：需求池 → 需求及功能映射 → 验收条件与计划 → 实现及交付证据 → 确认修订与标签。
- 业务、需求、功能及验收内容不变。本次基线标签名为 `docs-v1.5.1`，创建结果见执行报告与 Git。

## 1.5.0：首次整理基线

- 将已有业务架构、路线图、前端设计和设置设计纳入同一产品文档版本线；保留原文的业务边界、历史阶段和验收结论。当时外层保留了兼容入口，后由 1.5.1 移除。
- 建立需求主题编号、功能映射和交付证据入口。编号和映射用于追踪，不表示对原规划重新审批或确认新的软件交付范围。
- 文档基线标签：`docs-v1.5.0`。代码历史 tag `v1.0.0` 仍表示原 V1 软件验收里程碑。

后续 `1.5.x` 的已确认修订在此按版本倒序追加：记录需求编号、变更前后、原因、影响的设计/计划/验收条件及基线标签。讨论中的修改由普通 Git 提交留痕，不预先填写为已确认版本。
