# references

外部文章摘录与个人阅读笔记，**不是实现契约**。本目录的结论不进入需求、不进入路线图，也不用来判断实现是否正确。现行系统见 [../architecture/architecture.md](../architecture/architecture.md)；上下文公式见 [../architecture/context-management.md](../architecture/context-management.md)；业务术语见 [CONTEXT.md](../../CONTEXT.md)。

## 包含模块

| 文件 | 说明 |
|------|------|
| `secondbrainblog.md` | Second Brain 相关摘录 |
| `参考.md` | 其它阅读笔记 |
| `思考.md` | 个人思考（用户维护，本目录不代改） |

从原 `design/参考/` 迁入。

目录内还可能有未纳入导航的个人笔记（未跟踪，不入库）；它们同属非契约材料，不加入本表以免在干净克隆中产生断链。

## 基础使用

当背景材料读即可。若摘录与现行架构冲突（例如仍写屏幕 OCR），忽略摘录。
