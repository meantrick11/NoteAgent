## 1. 激发你的兴趣

### 为什么会需要 Python

长期使用计算机后，人们可能会想自动化某项任务，例如批量搜索替换文本、复杂地重命名和整理照片，或编写小型定制数据库、专用 GUI 应用和简单游戏。

专业开发者还可能遇到另一组成本：使用多个 C/C++/Java 库时，常见的“编写—编译—测试—重新编译”周期太慢；为库编写测试很繁琐；已有程序可以使用扩展语言，但不想为应用设计和实现一门全新语言。Python 正适合处理这些情境。

### 选择 Python 的对比依据

- **相对 Shell/批处理**：Shell 脚本最擅长移动文件和修改文本数据，却不适合 GUI 应用或游戏。Python 作为真正的编程语言，为大型程序提供了更多结构与支持。
- **相对 C/C++/Java**：这些语言即使写出第一版程序也可能花费大量开发时间；Python 更容易使用，可在 Windows、macOS 和 Unix 上运行，并能帮助用户更快完成任务。Python 还比 C 提供更多错误检查。
- **相对 Awk/Perl**：Python 内置灵活数组、字典等高级且更通用的数据类型，因此适用的问题领域更广；许多事情用 Python 完成至少同样容易。

这些比较说明的是各自在文中所述场景下的取舍，并不意味着一种语言在所有任务上都绝对优于另一种。

### 支撑开发效率的能力

#### 模块与标准库

程序可拆成模块并在其他 Python 程序中复用。Python 附带大量标准模块，它们既可作为程序的基础，也可作为学习编程的示例；其中一些提供文件 I/O、系统调用、套接字，甚至 Tk 等 GUI 工具包接口。

#### 解释执行与交互

Python 是解释型语言。由于不需要编译和链接，它可以节省大量开发时间。解释器还能交互使用，便于：

- 试验语言特性；
- 编写一次性程序；
- 在自底向上的开发中测试函数；
- 充当桌面计算器。

#### 代码为何通常更短、更易读

与等价的 C、C++ 或 Java 程序相比，Python 程序通常短得多，原文给出三个原因：

1. 高级数据类型可用一条语句表达复杂操作；
2. 语句分组依靠缩进，而不是起止括号；
3. 不需要变量或参数声明。

### 与 C 连接：扩展与嵌入

如果会 C，就容易给解释器加入新的内建函数或模块：既可让关键操作以最高速度执行，也可连接只有二进制形式的库，例如供应商专用图形库。反过来，还能把 Python 解释器嵌入 C 应用，把它作为该应用的扩展语言或命令语言。

### 名称与学习路线

Python 得名于 BBC 节目《Monty Python’s Flying Circus》，与爬行动物无关；文档甚至鼓励引用 Monty Python 的短剧。

学习语言最好的方式是使用它，因此教程邀请读者边读边操作解释器。下一章先说明解释器的使用机制；这部分虽然平凡，却是尝试后续示例所必需的。此后教程通过示例，从简单表达式、语句和数据类型讲到函数与模块，最后触及异常和用户自定义类等高级概念。
