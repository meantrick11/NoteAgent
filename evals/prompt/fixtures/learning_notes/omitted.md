## 为什么选择 Python

日常使用计算机时，重复任务很适合自动化。Python 易于使用，并可运行于 Windows、macOS 和 Unix，因此常能比开发 C/C++/Java 程序更快地产出结果。

与主要处理文件和文本的 Shell 脚本相比，Python 是一门真正的编程语言，能为大型程序提供更多结构。它也比 C 提供更多错误检查，并内置数组和字典等高级数据类型。

## 开发体验

Python 是解释型语言，不需要编译和链接。开发者可以通过交互式解释器试验语言功能、测试函数，也可把它当作计算器。

Python 程序通常比等价的 C、C++ 或 Java 程序短：

1. 高级数据类型能表达复杂操作；
2. 缩进承担语句分组；
3. 无需变量和参数声明。
