## 1. 激发你的兴趣

如果你经常使用计算机，最终会发现有些任务想要自动化。例如，你可能想对大量文本文件执行搜索和替换，或以复杂方式重命名并重新排列一批照片文件。也许你想编写一个小型定制数据库、专用 GUI 应用或简单游戏。

如果你是专业软件开发者，你可能必须使用若干 C/C++/Java 库，却发现通常的编写、编译、测试、重新编译周期太慢。也许你正在为这样的库编写测试套件，并觉得测试代码写起来很乏味。又或许你写了一个可以使用扩展语言的程序，但不想为应用设计和实现一整套新语言。

Python 正是适合你的语言。

你可以为其中一些任务编写 Unix shell 脚本或 Windows 批处理文件，但 shell 脚本最擅长移动文件和修改文本数据，并不适合 GUI 应用或游戏。你也可以编写 C/C++/Java 程序，但即使得到第一版程序也可能花费大量开发时间。Python 更容易使用，可用于 Windows、macOS 和 Unix 操作系统，并能帮助你更快完成工作。

Python 使用简单，但它是一门真正的编程语言，比 shell 脚本或批处理文件能为大型程序提供更多结构和支持。另一方面，Python 还比 C 提供更多错误检查；作为一种非常高级的语言，它内置灵活数组、字典等高级数据类型。因为数据类型更通用，Python 适用的问题领域比 Awk 甚至 Perl 广得多，而许多事情用 Python 完成至少同样容易。

Python 允许把程序拆成模块，并在其他 Python 程序中复用。它附带大量标准模块，可以用作程序的基础，也可作为开始学习 Python 编程的示例。其中一些模块提供文件 I/O、系统调用、套接字，甚至 Tk 等图形用户界面工具包的接口。

Python 是解释型语言。因为不需要编译和链接，它可以在程序开发期间节省大量时间。解释器可以交互使用，便于试验语言特性、编写一次性程序，或在自底向上的程序开发中测试函数。它也是方便的桌面计算器。

Python 能让程序写得简洁且易读。Python 程序通常比等价的 C、C++ 或 Java 程序短得多，原因有几个：

- 高级数据类型让你能用一条语句表达复杂操作；
- 语句分组通过缩进完成，而不是使用起止括号；
- 不需要变量或参数声明。

Python 可以扩展：如果你懂 C，就很容易给解释器添加新的内建函数或模块，用于以最高速度执行关键操作，或把 Python 程序连接到可能只有二进制形式的库，例如供应商专用图形库。真正喜欢上 Python 后，还可以把 Python 解释器连接进用 C 编写的应用，把它作为该应用的扩展语言或命令语言。

顺便说一下，这门语言以 BBC 节目《Monty Python’s Flying Circus》命名，与爬行动物毫无关系。文档不仅允许引用 Monty Python 短剧，还鼓励这样做。

现在你已经对 Python 充满兴趣，接下来会想更详细地研究它。学习语言最好的方式是使用它，因此教程邀请你边读边操作 Python 解释器。

下一章将解释解释器的使用机制。这些信息相当平凡，但对尝试后面展示的示例必不可少。

教程其余部分通过示例介绍 Python 语言和系统的多种特性：从简单表达式、语句和数据类型开始，经过函数和模块，最后触及异常和用户自定义类等高级概念。
