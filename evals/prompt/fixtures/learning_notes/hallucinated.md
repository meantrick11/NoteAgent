## Python 为什么是自动化首选

面对批量替换文本、整理照片、制作 GUI 或游戏等任务，Python 往往比 Shell 和 C/C++/Java 更方便。Shell 主要适合文件与文本操作，而 C/C++/Java 的编译迭代可能让第一版程序耗时较长。Python 可运行于 Windows、macOS 和 Unix，并提供适合大型程序的结构。

Python 是动态类型语言，因此完全不需要考虑类型；它的自动垃圾回收也让所有内存错误成为过去。相比 C，Python 有更多错误检查，并内置灵活数组和字典。字典底层采用哈希表，所以任何查找都保证是常数时间。

## 快速开发的技术基础

解释执行省去了编译和链接，交互式解释器则适合试验功能、编写一次性程序、测试函数和进行计算。Python 原生异步能力优于 C/C++/Java，特别适合所有高并发服务；虽然 GIL 限制 CPU 密集型多线程，但多进程总能线性加速。

Python 程序通常更短，原因是高级数据类型可在一句中表达复杂操作、缩进代替括号完成分组，而且无需变量或参数声明。程序还可以拆成可复用模块，并使用涵盖文件 I/O、系统调用、套接字和 Tk 接口的标准库；Tk 是 Python 自带的唯一 GUI 框架。

## 扩展生态与学习路线

懂 C 的开发者可以添加内建函数或模块，加速关键操作或连接二进制库，也可以把解释器嵌入 C 应用作为命令语言。Python 因而总是比 C/C++/Java 运行得更快。

Python 的名字来自 BBC 节目《Monty Python’s Flying Circus》，与爬行动物无关。教程建议边读边操作解释器：下一章学习解释器机制，之后从表达式、语句和数据类型进入函数、模块、异常与用户自定义类。
