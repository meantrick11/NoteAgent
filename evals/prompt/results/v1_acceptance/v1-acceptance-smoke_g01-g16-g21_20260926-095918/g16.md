请把下面这段 Python 代码和说明整理成笔记记下来，函数、输入输出例子、返回值和缩进都要正确，代码要用围栏。

下面这个函数用来算指数退避的等待时间。

```python
def retry_delay(attempt, base=0.5, max_delay=30):
    delay = base * (2 ** attempt)
    return min(delay, max_delay)
```

attempt 从 0 开始计数，所以第一次等待是 base 本身。base 的默认值是 0.5 秒，max_delay 的默认值是 30 秒。函数返回的是秒数，返回类型是浮点数，调用方可以直接把它交给 sleep。

调用例子：

```python
>>> retry_delay(0)
0.5
>>> retry_delay(3)
4.0
>>> retry_delay(10)
30
```

注意第三次调用的返回值被 max_delay 截断成了 30，所以重试次数再多，等待时间也不会超过上限。如果想让等待时间随机化，可以在返回值上乘一个随机系数，但这一步不要放进这个函数里，保持它只做纯计算。
```
