## 5. 输入

```text
请把下面这些 PowerShell 步骤整理成笔记记下来，参数、引号和路径示例都要保持原样，命令用围栏。

先确认要清理的目录和范围，把下面这条命令里的 -Path 换成实际目录再执行：

```powershell
Get-ChildItem -Path 'D:\backup' -Recurse -Filter *.log -File
```

确认结果没问题之后，加上时间条件，只挑出 7 天前的文件：

```powershell
Get-ChildItem -Path 'D:\backup' -Recurse -Filter *.log -File |
    Where-Object { $_.LastWriteTime -lt (Get-Date).AddDays(-7) }
```

最后把 Where-Object 的结果接到 Remove-Item 上删除。第一次执行一定要带 -WhatIf，它只打印将要删除的文件，不会真的删除：

```powershell
Get-ChildItem -Path 'D:\backup' -Recurse -Filter *.log -File |
    Where-Object { $_.LastWriteTime -lt (Get-Date).AddDays(-7) } |
    Remove-Item -WhatIf
```

确认 -WhatIf 的输出符合预期后，再去掉 -WhatIf 正式执行。单引号里的路径不会被变量展开，所以 D:\backup 这种写法要保留单引号；如果路径里需要变量，改用双引号。
```
