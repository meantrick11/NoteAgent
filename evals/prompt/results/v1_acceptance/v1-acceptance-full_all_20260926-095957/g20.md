## 5. 输入

```text
请把下面这段错误示例和修正版整理成笔记记下来，要明确标出哪一版是错的、错在哪里，不要把错误代码写成推荐实现，代码用围栏。

下面这个函数想把元素追加到列表里，但它是错的：

```python
def add_item(item, bucket=[]):
    bucket.append(item)
    return bucket
```

问题出在默认参数：默认值只在函数定义时求值一次，所以所有调用共用同一个列表。第一次调用 add_item('a') 得到 ['a']，第二次调用 add_item('b') 会得到 ['a', 'b']，而不是 ['b']。

修正版把默认值改成 None，在函数体里再建列表：

```python
def add_item(item, bucket=None):
    if bucket is None:
        bucket = []
    bucket.append(item)
    return bucket
```

这样每次不传 bucket 都会得到一个新列表，第二次调用 add_item('b') 返回 ['b']。如果确实想共用同一个列表，应该让调用方显式传入，而不是靠默认值隐藏这个共享状态。
```
