```markdown
## 同一 JSON 载荷上的对比

12 MB 的 JSON 载荷，单线程压缩：

- gzip 通常压到约 2.4 MB，耗时约 1.1 秒。
- zstd（level 3）压到约 2.1 MB，耗时 0.4 秒——这也是构建流水线常偏好它的原因。
- brotli（quality 5）夹在两者之间，约 2.2 MB，但需要 0.7 秒，且它在浏览器中的解压略慢。

## 更大归档上的差距

换到 100 MB 的日志归档，差距进一步拉大：gzip 需要 9.5 秒，zstd 需要 2.8 秒，而两者压缩后的体积相差不到 8%。

## 可用性限制

如果客户端是浏览器，通常只有 gzip 和 brotli 两个选项可用。
```
