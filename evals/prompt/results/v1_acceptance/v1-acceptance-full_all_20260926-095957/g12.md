```markdown
## 快速启动

在当前文件夹启动服务，监听 8000 端口：

```bash
python -m http.server 8000
```

## 文件在别处时指定目录

如果文件不在当前文件夹，用 `--directory` 把服务器指向那个目录：

```bash
python -m http.server 8000 --directory ./site
```

## 启动前确认端口空闲

启动之前，先确认端口没有被占用。

Windows：

```bash
netstat -ano | findstr :8000
```

在输出里找处于 listening 状态的那一行。

Linux：

```bash
ss -lntp | grep 8000
```

## 停止服务器

用 `Ctrl+C` 停止服务器。

## 端口已被占用

如果端口已经被占用，要么停掉占用该端口的进程，要么换一个端口。服务器无法绑定端口时会立即退出。
```
