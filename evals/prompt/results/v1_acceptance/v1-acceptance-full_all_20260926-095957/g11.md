```markdown
## 鉴权与可读范围

服务账号（service account）可以随时读取 metrics 端点，该调用从不改变服务器状态。客户端必须在每个请求的 `Authorization` 头中发送 API key，因为网关会以 401 拒绝匿名调用。

## 缓存、过期与源站降级

响应缓存通常在五分钟后过期，但源站（origin）可以用 `Cache-Control` 头覆盖这个时长。若源站暂时不可用，网关可能返回陈旧副本，最多三十秒。

## 密钥轮换

运维人员通常每九十天轮换一次密钥。轮换可能立即生效，所以客户端应从 secret store 重新读取密钥，而不是把它缓存在内存中。
```
