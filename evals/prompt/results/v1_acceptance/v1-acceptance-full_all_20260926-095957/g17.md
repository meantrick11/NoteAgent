请把下面这段 SQL 和表结构说明整理成笔记记下来，字段、过滤条件和排序都要保留，SQL 用围栏。

订单表 orders 的主要字段：id 是主键，user_id 是下单用户，status 是订单状态，amount 是金额，created_at 是下单时间，paid_at 是支付时间，未支付时为空。

```sql
CREATE TABLE orders (
    id INTEGER PRIMARY KEY,
    user_id INTEGER NOT NULL,
    status TEXT NOT NULL,
    amount NUMERIC NOT NULL,
    created_at TEXT NOT NULL,
    paid_at TEXT
);
```

下面这条查询取某个用户已经支付、且金额大于 100 的订单，按下单时间倒序，只看最近 20 条：

```sql
SELECT id, amount, created_at
FROM orders
WHERE user_id = ?
  AND status = 'paid'
  AND amount > 100
ORDER BY created_at DESC
LIMIT 20;
```

user_id 用占位符传入，不要拼字符串，避免注入。排序用 created_at 而不是 id，因为 id 只保证唯一，不保证和下单时间同序。如果要在列表里展示支付时间，需要另外 join 支付流水表，orders 上的 paid_at 只记最后一次支付的时间。
```
