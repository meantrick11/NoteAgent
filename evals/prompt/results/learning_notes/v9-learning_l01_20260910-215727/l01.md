如果你是专业软件开发人员，可能要同时使用多个 C/C++/Java 库，却发现通常的「编写 / 编译 / 测试 / 重新编译」循环太慢；也许你在为这样的库写测试套件，觉得写测试代码很枯燥；又或者你写的程序本可以用某种扩展语言，而你不愿为应用从零设计和实现一门全新的语言。Python 正是适合你的语言。

对其中一些任务，你可以写 Unix shell 脚本或 Windows 批处理文件，但 shell 脚本最擅长移动文件和修改文本数据，不适合 GUI 应用或游戏。你也可以写 C/C++/Java 程序，但即使只是第一版草稿程序，也可能耗费大量开发时间。Python 更易使用，可在 Windows、macOS 和 Unix 操作系统上运行，并能帮你更快完成工作。

Python 使用简单，但它是一门真正的编程语言，比起 shell 脚本或批处理文件，能为大型程序提供更多结构与支持。另一方面，Python 提供的错误检查也比 C 多；作为一门极高级语言，它内置了灵活数组、字典等高级数据类型。由于数据类型更通用，Python 能适用的问题域比 Awk 甚至 Perl 大得多，而许多事情在 Python 中至少和在这些语言中一样容易。

Python 允许把程序拆分成模块，供其他 Python 程序复用。它自带庞大的标准模块集合，可作为程序的基础，也可作为学习 Python 编程的示例；其中一些模块提供文件 I/O、系统调用、套接字，甚至与 Tk 之类 GUI 工具包的接口。

Python 是解释型语言，开发过程中无需编译和链接，能省下大量时间。解释器可以交互使用，便于试验语言特性、编写一次性程序，或在自底向上的开发过程中测试函数；它也是一个顺手的桌面计算器。

Python 能让程序写得紧凑、可读。与等价的 C、C++、Java 程序相比，Python 程序通常短得多，原因有几个：

- 高级数据类型允许用一条语句表达复杂操作；
- 语句分组靠缩进，而不是起止括号；
- 不需要变量或参数声明。

Python 可扩展：如果你会 C 编程，很容易为解释器添加新的内置函数或模块——既可以用于以最高速度执行关键操作，也可以把 Python 程序连接到只有二进制形式的库（如厂商专用的图形库）。等你真正上手后，还可以把 Python 解释器链接进用 C 写的应用，把它当作该应用的扩展语言或命令语言。

顺便一提，这门语言得名于 BBC 节目《蒙提·派森的飞行马戏团》（Monty Python's Flying Circus），与爬行动物毫无关系。在文档里引用 Monty Python 的段子不仅允许，而且受到鼓励！

既然你对 Python 已经兴致勃勃，自然会想更仔细地了解它。学习一门语言最好的方式就是使用它，因此本教程邀请你在阅读时动手玩一玩 Python 解释器。

下一章讲解使用解释器的具体机制。这些信息相当平常，但要想尝试后面给出的示例，它们是必需的。

教程其余部分通过示例介绍 Python 语言和系统的各种特性：从简单的表达式、语句和数据类型开始，经过函数与模块，最后涉及异常、用户自定义类等高级概念。
