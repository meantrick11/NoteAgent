### 需要自动化的任务

如果在计算机上做很多工作，你最终会发现有某项任务希望自动化。例如，对大量文本文件执行查找替换，或者以复杂的方式重命名和重新排列一批照片文件；也许你想写一个小型的自定义数据库、一个专门的 GUI 应用，或者一个简单的游戏。

如果你是专业软件开发者，可能不得不与多个 C/C++/Java 库打交道，却发现通常的编写/编译/测试/重新编译循环太慢；也许你在为这样的库编写测试套件，觉得写测试代码太繁琐；或者你已经写了一个可以使用扩展语言的程序，却不想为你的应用设计并实现一门全新的语言。Python 正是适合你的语言。

### 与其他方案的比较

对其中一些任务，你可以写 Unix shell 脚本或 Windows 批处理文件，但 shell 脚本最擅长移动文件和修改文本数据，并不适合 GUI 应用或游戏。你也可以写 C/C++/Java 程序，但即使只是得到一个初稿程序，也可能花费大量开发时间。Python 使用起来更简单，可在 Windows、macOS 和 Unix 操作系统上使用，并能帮助你更快地完成任务。

### Python 是一门真正的编程语言

Python 用起来简单，但它是一门真正的编程语言，为大型程序提供的结构和对大型程序的支持，远多于 shell 脚本或批处理文件。另一方面，Python 提供的错误检查也远多于 C；作为一种非常高级的语言，它内置了高级数据类型，例如灵活的数组和字典。由于数据类型更为通用，Python 适用的问题域比 Awk 甚至 Perl 大得多，而很多事情在 Python 里至少和在这些语言里一样容易。

Python 允许你把程序拆分为模块，以便在其他 Python 程序中复用。它附带大量标准模块，可以作为程序的基础使用——也可以作为开始学习用 Python 编程的示例。其中一些模块提供文件 I/O、系统调用、套接字，甚至链接到 Tk 这类图形用户界面工具包的接口。

Python 是一种解释型语言，在程序开发期间可以节省大量时间，因为不需要编译和链接。解释器可以交互使用，这使得试验语言特性、编写一次性程序，或在自底向上的程序开发中测试函数都变得容易。它也是一个方便的桌面计算器。

Python 让程序可以写得紧凑而可读。用 Python 写的程序通常比等价的 C、C++ 或 Java 程序短得多，原因有几个：

- 高级数据类型允许用一条语句表达复杂的操作；
- 语句分组通过缩进完成，而不是用开始和结束的括号；
- 不需要声明变量或参数。

Python 是可扩展的：如果你会写 C 程序，就很容易为解释器添加新的内置函数或模块，既能以最高速度执行关键操作，也能把 Python 程序链接到可能只有二进制形式的库（例如厂商专用的图形库）。一旦真正上手，你还可以把 Python 解释器链接进用 C 编写的应用，把它用作该应用的扩展或命令语言。
