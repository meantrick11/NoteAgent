### 与 Shell 脚本、C/C++/Java 的取舍

上面这些任务，可以用 Unix shell 脚本或 Windows 批处理文件来完成，但 shell 脚本最擅长移动文件和修改文本数据，并不适合 GUI 应用或游戏。也可以用 C/C++/Java 写程序，但即使只想做出第一版草稿程序，也可能花掉大量开发时间。相比之下，Python 用起来更简单，可在 Windows、macOS 和 Unix 操作系统上使用，能更快把活干完。

Python 用起来简单，但它是一门真正的编程语言：相比 shell 脚本或批处理文件，它能为大型程序提供多得多的结构和支持。另一方面，Python 的错误检查比 C 多得多；作为一门非常高级（very-high-level）的语言，它内置了灵活数组、字典这样的高级数据类型。由于数据类型更通用，Python 能适用的问题领域比 Awk 甚至 Perl 大得多，而很多事情在 Python 里至少和在这些语言里一样容易。

### 模块与标准库

Python 允许把程序拆分成模块，这些模块可以在其他 Python 程序中复用。它自带大量标准模块，既可作为自己程序的基础，也可当作学习 Python 编程的示例。其中有些模块提供文件 I/O、系统调用、套接字，甚至到 Tk 这类图形用户界面工具包的接口。

### 解释型语言与交互式使用

Python 是解释型语言，开发程序时不需要编译和链接，因此能省下大量时间。解释器可以交互式使用：便于试验语言的各种特性、写用完即弃（throw-away）的程序，或在自底向上的开发过程中测试函数。它同时也是一个顺手的桌面计算器。

### 简洁可读

Python 让程序写得紧凑、易读。等效的 Python 程序通常比 C、C++、Java 程序短得多，原因有几个：

- 高级数据类型允许用一条语句表达复杂操作；
- 语句分组靠缩进完成，而不是靠首尾括号；
- 不需要声明变量或参数。

### 可扩展与可嵌入

Python 可以扩展：如果你会 C 编程，往解释器里加一个新的内建函数或模块很容易——既可以用来以最高速度执行关键操作，也可以把 Python 程序链接到只以二进制形式提供的库（例如厂商专有的图形库）。一旦真正上了瘾，还可以把 Python 解释器链接进用 C 写成的应用程序，把它当作该应用的扩展语言或命令语言。
