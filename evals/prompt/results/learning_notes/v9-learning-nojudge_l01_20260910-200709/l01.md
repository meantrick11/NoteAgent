## 1. 激发兴趣

如果在计算机上做很多工作，最终总会发现有些任务想自动化。例如，你可能想在一大批文本文件上做查找替换，或以复杂方式重命名并重新排列一堆照片文件；也可能想写一个小小的自定义数据库、一个专用的 GUI 应用，或者一个简单的游戏。

如果你是专业软件开发者，可能得配合若干 C/C++/Java 库工作，却发现常见的写 / 编译 / 测试 / 再编译循环太慢；也可能在为这样的库写测试套件，觉得写测试代码是件乏味的事；或者已经写了一个程序，本可以用某种扩展语言，却不想为应用设计并实现一门全新的语言。

Python 就是为你准备的语言。

## 与 shell、C/C++/Java 的分工

对其中某些任务，你可以写 Unix shell 脚本或 Windows 批处理文件，但 shell 脚本最擅长搬运文件和修改文本数据，并不适合 GUI 应用或游戏。你也可以写 C/C++/Java 程序，但即使只是第一版程序，也可能花掉大量开发时间。Python 用起来更简单，可在 Windows、macOS 和 Unix 操作系统上使用，能帮你更快把活干完。

## Python 的特点

### 易用，却是真正的编程语言

Python 易用，但它是一门真正的编程语言：与 shell 脚本或批处理文件相比，它为大型程序提供了多得多的结构和支持。另一方面，Python 比 C 提供多得多的错误检查；作为一门甚高级语言（very-high-level language），它内置了灵活数组、字典等高层数据类型。由于数据类型更通用，Python 适用的问题领域比 Awk 甚至 Perl 大得多，而许多事情在 Python 里至少和在这些语言里一样容易。

### 模块与标准库

Python 允许你把程序拆成模块，以便在其他 Python 程序中复用。它自带大量标准模块，既可作为程序的基础，也可当作入门学习 Python 编程的示例。其中一些模块提供文件 I/O、系统调用、套接字（sockets），甚至像 `Tk` 这类图形用户界面工具包的接口。

### 解释型语言

Python 是解释型语言，开发过程中不需要编译和链接，能省下大量时间。解释器可以交互使用，因此便于试验语言特性、写一次性程序（throw-away programs），或在自底向上的程序开发过程中测试函数。它也是一个顺手的桌面计算器。

### 紧凑可读

Python 能让程序写得紧凑而可读。与等价的 C、C++ 或 Java 程序相比，Python 程序通常短得多，原因有几点：

- 高层数据类型允许用单条语句表达复杂操作；
- 语句分组靠缩进完成，而不是靠起止括号；
- 不需要变量或参数声明。

### 可扩展

Python 是可扩展的：如果会 C 编程，就很容易为解释器添加新的内置函数或模块，用来以最高速度执行关键操作，或把 Python 程序链接到只有二进制形式的库（例如厂商特定的图形库）。一旦真正上手，你还可以把 Python 解释器链接进用 C 写的应用，把它用作该应用的扩展语言或命令语言。

### 名字的由来

Python 得名于 BBC 节目 “Monty Python's Flying Circus”，与爬行动物无关。在文档里引用 Monty Python 小品不仅允许，而且受到鼓励。

下一章解释使用解释器的机制。这些信息相当平淡，但对试跑后面出现的示例来说必不可少。
