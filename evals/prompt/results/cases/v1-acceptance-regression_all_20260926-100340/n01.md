## 2. 使用 Python 的解释器

### 2.1. 唤出解释器

在可用的机器上，Python 解释器通常被安装为 `/usr/local/bin/python3.14`；把 `/usr/local/bin` 加入 Unix shell 的搜索路径后，键入 `python3.14` 即可启动。解释器也可能安装在别的位置。

在 Windows 上从 Microsoft Store 安装后，`python3.14` 可用；如果安装了 `py.exe` 启动器，则可以用 `py`。

退出时，在主提示符下 Unix 按 Control-D、Windows 按 Control-Z，退出状态码为 0；也可以输入 `quit()`。

另一种启动方式是把命令直接传给解释器：

```bash
python -c command [arg] ...
```

模块也可以当作脚本来运行：

```bash
python -m module [arg] ...
```

#### 2.1.1. 传入参数

解释器把脚本名与其他参数转化为字符串列表，存到 `sys` 模块的 `argv` 中，执行 `import sys` 即可访问。

- 未给定输入参数时，`sys.argv[0]` 是空字符串。
- 使用 `-c command` 时，`sys.argv[0]` 是 `-c`。
- 使用 `-m module` 时，`sys.argv[0]` 是包含目录的模块全名。

#### 2.1.2. 交互模式

在终端输入并执行指令时，解释器在交互模式中运行。主提示符通常为 `>>>`，次要提示符为 `...`。

### 2.2. 解释器的运行环境

#### 2.2.1. 源文件的字符编码

默认情况下，Python 源码文件的编码是 UTF-8。不使用默认编码时，把文件第一行写成：

```text
# -*- coding: encoding -*-
```
```
